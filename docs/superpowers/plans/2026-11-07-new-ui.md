# Yeni arayüz — uygulama planı

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Lumen'in arayüzünü tek birleşik tasarıma, üç hazır temaya ve token tabanlı renk/yazı tipi özelleştirmesine taşımak; isteğe bağlı durum çubuğu eklemek. Electron ve Tauri'de aynı çalışır.

**Architecture:** DOM ve JS modülleri yerinde kalır. 12 CSS dosyası (`style, design, photos, explore, tools, controls, format, polish, themes, run, extras`) yerine `app/ui/tokens.css` (tek token katmanı) + `app/ui/base.css` + `app/ui/c-*.css` (bileşen başına) gelir. Görünüm tercihi `prefs.appearance` altında toplanır; eski alanlar göç eder, silinmez.

**Tech Stack:** vanilla JS/CSS, mevcut CDP test altyapısı (`tests/ui`), Node 22 core testleri.

**Spec:** `docs/superpowers/specs/2026-11-07-new-ui-design.md`

## Global Constraints
- Dal: `ui-redesign` (`tauri-shell`'den). Yerel commit serbest, push/merge onaysız yok, Co-Authored-By yok.
- npm bağımlılığı yok; yazı tipi indirme yok (yalnızca sistem yazı tipleri).
- Her yeni metin EN + TR (`translations` sözlüğü). Çeviri taslakları DeepSeek flash'a verilebilir (`work/deepseek/ds.mjs`); son metni uygulayıcı kontrol eder.
- `window.lumen` / IPC sözleşmesi değişmez. Kullanıcı verisi bozulmaz; eski tercih alanları okunur, silinmez.
- Kontrast: metin/yüzey ve vurgu/vurgu-metni çiftleri ≥ 4.5:1 (her tema × mod).
- Animasyon ≤150 ms, `prefers-reduced-motion` ve `prefs.motion=false`'ta kapalı; polling yok.
- Composer `focusout` `relatedTarget` davranışı korunur (CLAUDE.md §17).
- UTF-8 düzenleme (PowerShell Get-Content/Set-Content ile Türkçe dosya yazma yok).
- Testler: `node --test "tests/core/*.test.mjs"`, `node --test --test-concurrency=1 "tests/ui/*.test.mjs"` (LUMEN_SHELL=electron|tauri). Assertion gevşetilmez; seçici değişikliği testle aynı commit'te.

## Review Focus
1. Eski kullanıcı tercihleri (desk/studio, özel vurgu rengi, yazı boyutu, koyu/açık) yeni sürümde kaybolmamalı.
2. Kullanıcı okunmaz renk seçerse (beyaz üstüne açık sarı) kaydedilmemeli, uyarı gösterilmeli.
3. Sistemde olmayan bir yazı tipi seçilirse makul bir yedeğe düşmeli, düzen bozulmamalı.
4. Bulut modeli seçiliyken hiçbir yerde "Yerel" yazmamalı; context gösterimi sağlayıcının sayımına geçmeli.
5. 800×600 ve %150 Windows ölçeğinde taşma olmamalı.
